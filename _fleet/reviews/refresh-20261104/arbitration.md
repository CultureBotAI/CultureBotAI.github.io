# Refresh audit rulings — November 4, 2026

The root editor arbitrates disagreements between the browser auditors and their
independent skeptics. These rulings apply the existing 24-feature catalogue;
the catalogue, census and graph methodology are unchanged.

- **Schema documentation.** A visible link to raw LinkML YAML establishes
  access to the schema source. It does not establish published schema
  documentation. TraitMech retains `partial`, with its note corrected to
  acknowledge the working source link. Apply the same distinction to the
  other sites. Generated schema documentation or an explanatory schema guide
  can support `present`.
- **Bulk downloads.** A navigation index or coordinate array can cover every
  identifier without exporting the records. Sites with only those indexes,
  per-record files, or repository links receive `partial`; the note should
  still state that the complete index is available. A linked bulk export of
  the record corpus supports `present`. This follows the existing distinction
  between an export of all records and partial exports; it applies equally
  to TaxonMech and the smaller corpora.
  PathwayMech's KGX download remains `present`: the 280-record manifest
  covers 5,466 nodes and 14,788 mechanistic edges, with evidence, reference
  metadata and endpoint qualifiers. It exports scientific content across
  the corpus, rather than just navigation fields. The catalogue does not
  require a lossless copy of every YAML field or history event.
- **Community-derived ingredient provenance.** Both independent counters
  find 18 current ingredient records with `communitymech-unmapped` synonyms.
  Only 17 also contain a literal imported `source_id=communitymech.ingredient:`
  value. The directory describes the measured synonym provenance and does
  not claim that every one of the 18 has that literal source identifier.
- **TraitMech writer coverage.** The source confirms reuse of the curation
  and validation helpers. The audit did not establish a denominator for
  “nearly every write script,” so the prose names verified examples instead.

The TraitMech canary passed the auditor and skeptic before the fleet browser
audits were delegated. It covers all 24 criteria, actual searches and filters,
URL restoration, record views, downloads, theme persistence, 390 px layouts
and failed data requests. Its compact receipts preserve the deployment ID,
latest successful status, response freshness and source evidence.
