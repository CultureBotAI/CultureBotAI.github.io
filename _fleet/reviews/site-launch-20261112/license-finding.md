# CofactorMech and AssayMech code licenses are misidentified

The directory currently labels these repositories' original code as BSD-3-Clause
in their graph entries and audit notes. Both repositories instead dedicate their
original code and schemas under CC0 1.0 and license curated records under
CC-BY-4.0, retaining upstream notices.

This is already true at the directory's existing corpus pins:

- [CofactorMech LICENSE at 131fc3e](https://github.com/CultureBotAI/CofactorMech/blob/131fc3ea47615a29bde04a3185b29f03edf2ada1/LICENSE)
- [AssayMech LICENSE at 95a01f4](https://github.com/CultureBotAI/AssayMech/blob/95a01f4981cbdf70e2e135d55d4d8f2f464a6e12/LICENSE)

The new website footers accurately repeat those terms, making the directory's
contradiction visible when readers follow the new links.

Correct the two repositories' claims and qualify the general suite-policy prose
where needed. Preserve upstream terms, existing corpus pins, and unrelated
repositories' license descriptions. Ensure maintained notes and their generated
audit copy agree, without presenting a new corpus observation.
